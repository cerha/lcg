# Changelog

All notable user visible changes to LCG.  The entries are brief, see the
documentation of the linked code for details.  The rules for maintaining this
file are described in [doc/standards/changelog.md](doc/standards/changelog.md).

## 0.9.2 (2026-11-04)

### HTML
- Right click invoking a popup menu (such as the menu of actions of a table
  row) no longer displays also the browser's own context menu.
- A popup menu invoked by mouse (click or right click) doesn't indicate the
  keyboard focus of its first item until the user starts using the keyboard.

## 0.9.1 (2026-11-04)

### HTML
- New JavaScript function [`lcg.initial_focus()`](javascript/lcg.js) moving
  the focus on page load.  The page is not scrolled when the element is
  visible and the focus indication appears only after the user starts
  interacting with the page
  ([#520](https://itsng.oui.technology/its/issues/520)).
- New attribute `formaction` of [`HtmlGenerator.button()`](lcg/export/html.py).

#### Accessibility
- [`Dropdown`](lcg/widgets.py) moves the focus to its button when the page
  is loaded with the URI fragment `focus-<id>` (where `<id>` is the widget
  id), so that the links of the dropdown may keep the focus on it when they
  reload the page ([#520](https://itsng.oui.technology/its/issues/520)).
- Only one link of an expanded [`Dropdown`](lcg/widgets.py) is in the Tab
  order (the arrow keys move between the links), so Tab leaves the dropdown
  instead of passing through all its links
  ([#520](https://itsng.oui.technology/its/issues/520)).

## 0.9.0 (2026-10-21)

### Common
- **Incompatible:** Python 2.7 support dropped, LCG requires Python 3.5 or
  later.  Python 2.7 deployments may stay with 0.8.2, which pip selects
  automatically there.
- **Incompatible:** [`Resource`](lcg/resources.py) content may only be
  bytes (file-like objects are not accepted).
- `svglib` moved to the `pdf` extra.
- Czech dates are separated by no-break spaces, so that speech synthesizers
  read them as dates ([#476](https://itsng.oui.technology/its/issues/476)).
- Fixed a circular import between the Braille and Nemeth modules.

### HTML
- New widgets [`Dropdown`](lcg/widgets.py) and `DropdownSelection`
  displaying a set of links (such as a selection of a value or an index) in a
  dropdown panel, with keyboard navigation also between links displayed in
  rows.  Without JavaScript the content is displayed directly, secondary
  choices may be left out.  They replace the former listbox based
  `DropdownSelection` widget
  ([#493](https://itsng.oui.technology/its/issues/493)).
- New generic icons drawn by SVG masks, referred to by class names (such as
  `search-icon`) or CSS custom properties (such as `--lcg-search-icon`).
  They scale with the text and follow its color.  The widget icons use them
  too, the icon sprite was removed
  ([#493](https://itsng.oui.technology/its/issues/493)).
- Wide tables and preformatted text scroll horizontally instead of
  overflowing the layout.
- Popup menus are positioned relative to the viewport, so they are not
  clipped by scrollable containers.
- The JavaScript translation catalogs are embedded in the exported pages, so
  the texts displayed by JavaScript are translated already on the first page
  load.  The catalogs only contain the messages used in JavaScript.
- Fixed URI arguments generated by `HtmlGenerator.uri()`, which are now
  separated by `&`, as `;` is no longer recognized by Python 3.9.2 and newer
  ([#472](https://itsng.oui.technology/its/issues/472)).
- Fixed hiding all headings within notebook pages, including the headings of
  collapsible sections ([#474](https://itsng.oui.technology/its/issues/474)).
- Fixed extraction of translatable strings from the JavaScript sources.

#### Accessibility
- Collapsible sections are keyboard operable, the heading text is wrapped in
  a button which carries `aria-expanded` and `aria-controls`
  ([#474](https://itsng.oui.technology/its/issues/474)).
- The audio player position is an ARIA slider operable by keyboard (arrows,
  PageUp/PageDown, Home/End) and announcing the position with the track
  duration ([#481](https://itsng.oui.technology/its/issues/481)).
- Abbreviations are no longer named by `aria-label`, which made Safari
  present them as empty groups
  ([#476](https://itsng.oui.technology/its/issues/476)).

### Other formats
- Fixed `braille_presentation()` on Python 3.

## 0.8.2 (2026-07-29)

Packaging and release tooling only, no user visible changes.

## 0.8.1 (2026-07-29)

### Common
- The runtime data (resources, translations and documentation) are kept in
  the `assets` directory of the package.
- Fixed missing Czech translations of the media player controls and foldable
  widget labels.
- No warning about missing translations for the C/POSIX locale.

### HTML
- **Incompatible:** [`HtmlExporter`](lcg/export/html.py) exports HTML 5.
  `Html5Exporter` and `XhtmlGenerator` are deprecated aliases, XHTML is only
  produced by the EPUB exporter.  The obsolete meta tags and the default
  `type` attributes of scripts and style sheets are no longer exported.
- The JavaScript translation catalogs are announced by `<link rel="gettext">`
  in the page head, so they are found also under versioned resource URIs.
  The domains are determined by scanning the scripts.  The JavaScript UI
  language follows the page language.
- **Incompatible:** The Escape command of the foldable tree does nothing by
  itself, the applications define where the focus goes.
- Fixed a failing page initialization when a JavaScript translation catalog
  is missing.

#### Accessibility
- The keyboard focus is indicated consistently on all focusable elements by
  an outline, preserved also in the forced colors mode.
- Foldable tree expanders are operable by keyboard (Enter and Space).
- Hidden menus and auxiliary controls are kept out of the tab order, menus
  are traversed by arrow keys.
- Fixed keyboard operation of menus and foldable trees.

## 0.8.0 (2026-07-24)

### HTML
- **Incompatible:** JavaScript rewritten to ES6 and jQuery (Prototype is no
  longer used), minified on build.
- JavaScript UI strings translated through Jed.
- Asynchronous submission of an existing form by `lcg.Widget._ajax()`.
- Cookies set by JavaScript have `SameSite=Lax`.
- Fixed popup menu invocation by keyboard and initial item selection.

## 0.7.0 (2025-10-02)

The first version published on PyPI and the first release since 0.6.1.

### Common
- Python 3 support (Python 2.7 still supported).
- Packaged by Flit as `lcg-framework` with the extras `pdf`, `plot`,
  `braille` and `all`.  The resources are included in the package and the
  command line tool is run as `python -m lcg.make`.
- **Incompatible:** `lcg.config` removed.
- New plots ([`LinePlot`](lcg/plot.py), `BarPlot`) with grid lines,
  additional lines, locale specific date labels and custom axis label
  formatting, exported to HTML and PDF.
- Structured text supports generic containers with ARIA roles and labels,
  collapsible panes and sections and embedded interactive exercises.
  Links are protected against XSS.
- New functions [`lcg.sec()`](lcg/content.py) and `lcg.container()`,
  [`Resource`](lcg/resources.py) content may be passed to the constructor.
- **Incompatible:** Flash (SWF) video and audio dropped, audio is played by
  jPlayer, video by HTML 5.
- Interactive exercises reimplemented (new exercise types, authoring help,
  non-interactive export).
- Inline markup parser replacing `FormattedText` and `MarkupFormatter`, new
  inline elements (superscript, subscript), figures, quotations and
  abbreviations.
- MathML support in HTML, PDF and Braille output.
- HTML processor reading content created in HTML editors.
- Fixed `pgettext()` and time zone conversion of dates without time.

### HTML
- JavaScript widgets moved from Wiking: popup menu, foldable tree, notebook,
  collapsible pane, dropdown selection, tooltip and button.
- Image preview by Photoswipe instead of Lightbox.
- Explicit table column widths.
- Optional conversion of SVG to PNG.
- HTTPS YouTube and Vimeo links, embedded videos are wrapped for styling and
  have a default title.
- New HTML generator tags `nav`, `i` and `time`, attributes `async`,
  `integrity`, `crossorigin`, `multiple`, ARIA and `data-*` attributes and
  HTML 5 input types.  **Incompatible:** Removed
  `HtmlGenerator.script_write()` and the `options` argument of
  `HtmlGenerator.select()`.
- Improved styles of the foldable tree, collapsible sections, notebook and
  popup menus.

#### Accessibility
- ARIA support of the popup menu, foldable tree and collapsible pane widgets
 .
- Fixed the accessibility of collapsible panes.
- Relative font sizes instead of fixed ones.

### Other formats
- Braille output through liblouis with Nemeth math, tables, page numbers and
  printer selection.
- EPUB 3 export with metadata and cover images.
- PDF: fixed and percentage container sizes and padding, font and background
  colors, boxes with custom width, colors and rounded corners, letter list
  item indexes, image links, reimplemented subscripts and superscripts,
  suppressible table cell padding, invariant output.
- Fixed PDF font search and DejaVu font paths.

## 0.6.1 (2012-03-30)

### Common
- Fixed `LocalizableDateTime` cloning.

## 0.6.0 (2012-03-20)

### Common
- Generalized localization with date and time conversions (new class
  `Localizer`, `Exporter.localizer()` replaces `translator()`,
  `Localizable.translate()` renamed to `localize()`, old names kept as
  aliases).
- `Section` description, formatted text in headings, new function
  `format()` for translatable string formatting, localized country names.
- Structured text parser rewritten for more flexible contextual parsing
  (such as nested constructs in list items), table row iterators, parameters
  and presentation defined in documents.
- `Container.path()` renamed to `section_path()`.
- Python 2.6 support, unicode accepted where str was expected.
- Fixed `Monetary.transform()`, locale specific formatting of integers and
  precision of translatable decimal numbers.

### HTML
- HTML 4.0 Strict instead of Transitional.
- Image thumbnails.

### Other formats
- Major PDF output improvements.

## 0.5.1 (2011-01-17)

### Common
- The `LCGDIR` environment variable is only used by the `lcgmake` script.

### HTML
- `HtmlGenerator.button()` always produces the `<button>` tag.
- Styling of list items.

## 0.5.0 (2010-11-22)

### Common
- **Incompatible:** `SectionContainer` deprecated in favor of `Container`,
  which handles sections transparently.  The `Container` argument `id` is
  deprecated in favor of `name`.
- Tables allow more flexible structures and the structured text parser
  detects column headers and cell alignment.
- The condition evaluation namespace of `MacroParser` is restricted
  (security fix).

### HTML
- Embedding YouTube and Vimeo videos.
- The lists of style sheets and scripts in the HTML head may be overridden.

### Other formats
- PDF export usable for all generic content elements.

## 0.4.0 (2010-01-21)

### Common
- Video embedding, generalized audio embedding.
- **Incompatible:** Macro parser resurrected and improved.
- Explicit image sizing in structured text.

## 0.3.7 (2009-09-21)

### Common

### Common
- Eurochance project specific files removed.
- **Incompatible:** Document structure processing separated from the source

  in the `Exporter` class, generalized resource construction.
- Convenience functions for content construction.

### HTML
- Improved navigation within statically generated pages.

## 0.3.4 (2006-12-04)

- **Incompatible:** Export functionality moved from the content classes to
  the exporter classes.
- Polish translations including the formatting manual.

### HTML
- Improved HTML generation.

## 0.3.3 (2006-07-28)

- Deferred translation at export time.
- **Incompatible:** The output language is given by the `lang` argument of

- Fixed back references from section titles to the table of contents.
